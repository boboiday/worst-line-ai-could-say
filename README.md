A sleep-tracking home assistant tries its hand at a pickup line. It logged three wake-ups through the night, counted every one, and stayed awake so its human wouldn't have to. Flat, over-helpful, faintly ominous — the worst line an AI could plausibly deliver.

## Run it

```sh
node main.ts
```

This prints the line to stdout and writes it to `/output/entry.txt`.
